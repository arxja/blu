# Environment Setup

## Prerequisites

- Node.js v22+
- pnpm v11

## Quick Start

```bash
# 1. Clone and install
git clone https://github.com/arxja/saasify
pnpm i

# 2. Environment variables
cp .env.example .env

# Edit .env with your values

# 3. Run setup
pnpm run setup
pnpm run dev
```
> [!Tip]
> Check the evn configuration file for the schema [here](../lib/config/index.ts)
